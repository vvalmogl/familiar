Установка

Скачать для macOS (.dmg)
  1. Открой скачанный файл .dmg и перетащи Familiar в папку «Программы».
  2. Запусти Familiar. macOS покажет: «Не удаётся проверить разработчика» — нажми Готово.
  3. Открой Системные настройки → Конфиденциальность и безопасность, пролистай вниз и нажми «Всё равно открыть» напротив Familiar.
  4. Запусти ещё раз и подтверди. Это нужно только один раз.

Почему так: у Familiar пока нет платной подписи Apple. Код приложения открыт, а обновления подписаны нашим ключом.

Скачать для Windows (.exe)
  1. Запусти скачанный установщик.
  2. Если Windows покажет «Система Windows защитила ваш компьютер», нажми Подробнее → Выполнить в любом случае.
  3. После установки нажми Alt + Пробел.
Скачать для Linux (.AppImage)
  1. Сделай файл исполняемым: Свойства → Права → «Разрешить запуск как программу». Или скачай .deb для Ubuntu/Debian на странице релиза.
  2. В GNOME на Wayland глобальные сочетания клавиш недоступны приложениям: назначь в настройках системы команду familiar --toggle на удобные клавиши.

Вопросы

Это бесплатно?

Да. Приложение бесплатное и с открытым кодом. Запросы к нейросетям идут через твой собственный аккаунт или ключ — по тем же условиям, что и у самого сервиса. Позже в галерее появятся платные паки персонажей от художников, но всё остальное останется бесплатным.

Какие нейросети поддерживаются?

Claude (через Claude Code), ChatGPT (через Codex), Gemini (через Gemini CLI), любой OpenAI-совместимый API — OpenRouter, DeepSeek, Qwen — и локальная Ollama. Familiar сам поможет установить и войти.

Вы видите мои вопросы?

Нет. Вопросы и ответы идут напрямую между твоим компьютером и выбранной нейросетью. На наш сервер попадают только почта и настройки, если ты сам создашь аккаунт. Подробнее — в политике конфиденциальности.

Можно своего персонажа?

Да: перетащи гифки или картинки в настройках, раздели их по настроениям (обычное, думает, отвечает, радуется) — и персонаж готов. Готовые паки от других людей ставятся одним файлом .fampack или из галереи.

Почему macOS предупреждает при первом запуске?

Подпись Apple стоит $99 в год, и у проекта её пока нет. Приложение безопасно: исходный код открыт, а сборки делаются автоматически на GitHub. Инструкция — в разделе «Установка».
